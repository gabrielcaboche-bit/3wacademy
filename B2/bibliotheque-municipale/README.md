## Précisions sur la réalisation

Le fichier `requests.http` a été préparé avec l’aide de l’IA afin de faciliter les tests manuels de l’API.

Les premières versions des fichiers Pug ont été réalisées à la main. L’IA a ensuite été utilisée pour améliorer la qualité du balisage HTML généré et de la mise en forme CSS.
